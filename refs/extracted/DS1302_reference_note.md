## 可引用知识点

DS1302 是实时时钟芯片，通常用于保存年、月、日、星期、时、分、秒等时间信息，并带有少量 RAM 与备用电池/涓流充电相关接口。它通过三线串行接口与单片机通信，典型控制信号包括 CE/RST、SCLK 和 I/O。若后续要记录智能小车运行时间、清扫时长或定时启动时间，可将 DS1302 作为扩展模块接入 51 单片机。

## 在课题 3 中的处理

课题 3 的基础功能由 STC89C52、LCD1602、HC-SR04、L293D 和直流电机即可完成，DS1302 不参与第一版硬件连接和汇编程序。说明书中可将其列为“任务书要求收集的扩展器件资料”，并说明本设计优先使用单片机定时器完成测距计时和软件延时。
